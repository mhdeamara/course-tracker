# תוסף Chrome — מעקב קורסים

חלון קטן מהסרגל של Chrome: מה מוגש היום, מה באיחור, 7 הימים הקרובים, ספירה לאחור למבחנים, ונקודות/רמה/יעד יומי. מונה על האייקון (כמה להיום + באיחור). כפתור "פתח את האתר" ו"רק 5 דקות", וסימון ✓ שעובר דרך האתר עצמו (אותן נקודות, אותו יומן, אותו "בטל").

## התקנה (בלי חנות)
1. מורידים את קובץ ה-ZIP שקיבלתם ופותחים אותו לתיקייה קבועה (למשל `מסמכים\course-tracker-extension`). **לא** למחוק או להזיז אותה אחר כך — Chrome טוען את התוסף מהתיקייה הזאת.
   (או: משכפלים את הריפו, והתיקייה היא `extension/`.)
2. ב-Chrome פותחים `chrome://extensions`.
3. מדליקים **מצב מפתחים** (Developer mode) — מתג בפינה העליונה.
4. לוחצים **טען תוסף לא ארוז** (Load unpacked) ובוחרים את התיקייה (זאת שיש בה `manifest.json`).
5. מצמידים את האייקון: סמל הפאזל 🧩 ליד שורת הכתובת → נעץ ליד "מעקב קורסים".
6. פותחים את האתר פעם אחת: https://mhdeamara.github.io/course-tracker/ — מעכשיו התוסף מציג את הנתונים.

## מצב מקומי (ברירת המחדל)
- בלי חשבון ובלי שרת. הנתונים שלכם נשארים בדפדפן שלכם.
- כשהאתר פתוח, הוא שולח לתוסף תמונת מצב קטנה (שמות קורסים, כותרות ותאריכים, מבחנים, שעות שיעור, סיכום נקודות). בלי הערות, בלי קישורים, בלי פרטי התחברות.
- בחלון כתוב "עודכן לפני…" — זה מתי האתר היה פתוח לאחרונה. המונה וה"באיחור" מתעדכנים לפי התאריך גם כשהאתר סגור.
- אין צורך להגדיר כלום. אם יש לכם עותק משלכם של האתר בכתובת אחרת: ⚙ הגדרות → כתובת האתר.

## מצב מחובר (רק עם פרויקט Supabase משלכם)
⚙ הגדרות → "חיבור לחשבון": כתובת הפרויקט + המפתח **הציבורי** (anon / publishable), ואז אימייל וסיסמה. הסיסמה לא נשמרת. התוסף רק **קורא** את השורה שלכם (אותה הגנת RLS כמו באתר) ומתרענן כל כמה דקות. "התנתק" מוחק את ההתחברות.

## התראות אזכרות
כשמתחיל חלון אזכרות הבוקר/הערב והאתר **סגור**, מופיעה התראה אחת (אם עוד לא הושלמו). לחיצה פותחת את מסך הקריאה. כשהאתר פתוח — הוא מציג את הכרטיס שלו. אפשר לכבות בהגדרות.

## עדכון לגרסה חדשה
מחליפים את תוכן התיקייה בקבצים מה-ZIP החדש (באותה תיקייה, אותו שם), ואז ב-`chrome://extensions` לוחצים ⟳ על הכרטיס של התוסף. ההגדרות נשמרות. (אם מזיזים את התיקייה למקום אחר, Chrome רואה בזה תוסף חדש וההגדרות מתאפסות.)

## "השבת תוספים במצב מפתחים"?
Chrome מציג לפעמים, בפתיחה, הודעה על תוספים במצב מפתחים או "לא מחנות האינטרנט של Chrome". זה רגיל לכל תוסף שמותקן ככה, לא סימן לבעיה בתוסף. לוחצים "ביטול"/סוגרים את ההודעה — **לא** "השבת" — והתוסף ממשיך לעבוד. אם בכל זאת הושבת: `chrome://extensions` → מדליקים אותו שוב.

## הרשאות — ולמה
| הרשאה | למה |
|---|---|
| `storage` | לשמור את תמונת המצב האחרונה וההגדרות, בתוך התוסף בלבד |
| `alarms` | לעדכן את המונה (גם בחצות) ולרענן את מצב מחובר כל כמה דקות |
| `notifications` | התראת אזכרות כשהאתר סגור (אפשר לכבות בהגדרות) |
| גישה ל-`mhdeamara.github.io/course-tracker` בלבד | לקבל את תמונת המצב מהאתר, ולמצוא כרטיסייה פתוחה שלו ("פתח את האתר", ✓) |
| `scripting` + כתובת אחרת (אופציונלי) | רק אם משנים את כתובת האתר בהגדרות — Chrome שואל אז על הכתובת הזאת בלבד |

אין גישה לאתרים אחרים, אין קוד מרוחק, ואין שום סוד בקבצים. גישה ל-Supabase לא דורשת הרשאה מיוחדת: הוא מאשר בקשות מכל מקור, וההגנה היא ה-RLS.

## למפתחים
- הלוגיקה המשותפת עם האתר נמצאת ב-`lib/` (`utils.js`, `game.js`, `stats.js`, `adhkar.js`, `ext-snapshot.js`) — **העתקים** של הקבצים ב-`js/`. אחרי שינוי באתר: `node tools/ext-sync.mjs`. הבדיקה `tests/ext.test.js` נכשלת אם הם לא זהים.
- ZIP לשיתוף: `node tools/pack-extension.mjs` (מתוך git בלבד, אחרי בדיקת סודות) → `dist/`.
