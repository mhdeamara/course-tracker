# 📚 הקורסים שלי: מערכת מעקב אישית

אתר אישי למעקב אחרי הקורסים. עובד גם מקומית (פתיחת `index.html`) וגם כאתר עם סנכרון בין המחשב לטלפון.

## איך פותחים
1. לחיצה כפולה על `index.html`. הוא נפתח בדפדפן.
2. מומלץ לפתוח ב-**Chrome** או ב-**Edge**, ולשמור את הדף במועדפים (Ctrl+D).
3. כדי לפתוח בטלפון, ראה בהמשך "שימוש בטלפון".

> הנתונים נשמרים **בדפדפן שבו פתחת**. אם תפתח את הקובץ בדפדפן אחר, תראה מערכת ריקה. אפשר להעביר את הנתונים עם ייצוא וייבוא.

## גיבוי ושחזור (חשוב!)
הנתונים נמחקים אם מנקים את נתוני הגלישה בדפדפן. לכן:

- **ייצוא גיבוי:** הגדרות ← "ייצוא גיבוי". קובץ JSON יורד לתיקיית ההורדות.
- **שחזור:** הגדרות ← "ייבוא גיבוי", ואז בוחרים את הקובץ. אם התחרטת, Ctrl+Z מבטל.
- **שמירה אוטומטית לקובץ** (Chrome/Edge): הגדרות ← "בחר קובץ לשמירה אוטומטית". מומלץ לבחור קובץ בתוך OneDrive, וכך יש גם גיבוי בענן. מאותו רגע כל שינוי נשמר לקובץ.
  אחרי שסוגרים ופותחים את הדפדפן, יופיע כפתור "אשר גישה לקובץ". צריך ללחוץ עליו פעם אחת, זו דרישת אבטחה של הדפדפן.
- אם עברו יותר מ-7 ימים בלי גיבוי, תופיע בדשבורד תזכורת עדינה.

## תכנית הלימודים (קטלוג הפקולטה)
בתפריט **"תכנית לימודים"** יש את כל מקצועות מסלול הנדסת חשמל (קטלוג תשפ״ו), מסודרים בלשוניות:
- **חובה** — לפי השיבוץ המומלץ בסמסטרים 1–7.
- **קבוצות התמחות** — 13 השרשראות, עם מקצועות החובה של כל קבוצה וכמה מקצועות צריך. צריך להשלים לפחות 3.
- **בחירה פקולטית**, **מעבדות**, **בחירה חופשית** — הרשימות והכללים.

לחיצה על **"הוסף"** יוצרת את הקורס (שם, מספר, נקודות ומבנה סטנדרטי) בסמסטר שנבחר למעלה.
קורס שכבר אצלך מסומן **"אצלי"** — ההתאמה לפי מספר הקורס, אז כדאי למלא מספר גם בקורסים שהוספת ידנית (גם המספר הישן בן 6 הספרות עובד).
בראש הדף רואים כמה נקודות חובה ובחירה פקולטית יש בקורסים שלך וכמה קבוצות הושלמו. **זה לא תחליף לבדיקה מול הקטלוג הרשמי והמזכירות.**

## הוספת קורס חדש
1. בדשבורד לוחצים **"קורס חדש"** (או מקש `n`).
2. ממלאים שם, מספר קורס, צבע וסמסטר, ואפשר גם קישורים ותאריכי מבחנים.
3. משאירים את הסימון על "צור מבנה סטנדרטי" כדי לקבל 13 הרצאות, 13 תרגולים ו-5 ש"ב (את התבנית אפשר לשנות בהגדרות).
4. בתוך הקורס, **"פריטים בבת אחת"** יוצר למשל 6 שורות "ניסוי {n}" בלחיצה אחת.

## שימוש יומיומי
| מה | איך |
|---|---|
| סימון V | לוחצים על הריבוע, או Space על שורה |
| הערה | אייקון הדף בשורה, או Enter. נשמר תוך כדי הקלדה |
| נוסחה בהערה | `$x^2$` בתוך שורה, `$$\int f\,dx$$` בשורה נפרדת |
| סטטוס אחר (בתהליך / צריך לחזור) | לחיצה על התגית הצבעונית בשורה |
| ⭐ לחזור לפני המבחן | הכוכב בשורה (או `f`). הכול מתרכז ב"חזרה למבחן" |
| תאריך יעד | אייקון לוח השנה בשורה |
| סידור מחדש | גוררים מהנקודות (⠿) בצד השורה או הקטגוריה |
| ביטול פעולה | Ctrl+Z, או כפתור ↶ למעלה |
| כל הקיצורים | מקש `?` |

## סנכרון בין מחשב לטלפון
הסנכרון עובד דרך **Supabase** (מסד נתונים חינמי בענן), והאתר מתארח ב-**GitHub Pages**.

**איך זה עובד:** כל שינוי נשמר מיד בדפדפן ונשלח לענן תוך כשנייה וחצי. כל מכשיר בודק כל 20 שניות, וגם כשחוזרים ללשונית, אם יש שינויים ממכשיר אחר. בלי אינטרנט ממשיכים לעבוד כרגיל, והשינויים נשלחים כשהחיבור חוזר. אם שני מכשירים שינו נתונים באותו זמן, המערכת שואלת איזו גרסה להשאיר.

### הגדרה (פעם אחת)
1. פותחים חשבון ב-[supabase.com](https://supabase.com) ויוצרים פרויקט חדש (אזור: Frankfurt / Central EU).
2. **SQL Editor** ← New query ← מדביקים את כל התוכן של `supabase/schema.sql` ← **Run**.
3. **Project Settings ← API Keys**: מעתיקים את **Project URL** ואת המפתח **anon / publishable** לקובץ `js/config.js`.
   המפתח הזה מיועד להיות גלוי. ההגנה על הנתונים היא בהרשאות שב-`schema.sql`: כל משתמש רואה רק את השורה שלו.
4. **Authentication ← URL Configuration**: ב-Site URL שמים את כתובת האתר ב-GitHub Pages.
5. נכנסים לאתר ← הגדרות ← **"הרשמה (פעם ראשונה)"** ← מאשרים את המייל ← **"התחבר"**.
6. **חשוב:** אחרי שנרשמת, ב-**Authentication ← Sign In / Providers** מכבים את **Allow new users to sign up**, כדי שאף אחד אחר לא יוכל לפתוח חשבון באתר שלך.
7. בטלפון: פותחים את כתובת האתר, מתחברים, ובוחרים **"הוסף למסך הבית"** (בכרום: ⋮ ← "התקן אפליקציה"; באייפון: שיתוף ← "הוסף למסך הבית").

### לשים לב
- בתוכנית החינמית, פרויקט שלא נעשה בו שימוש **שבוע שלם** נכנס להשהיה. במקרה כזה נכנסים ל-supabase.com ולוחצים **Restore**. הנתונים לא נמחקים.
- במחשב, הקובץ המקומי (`index.html` מהתיקייה) והאתר ב-GitHub Pages הם שני "מכשירים" נפרדים. מתחברים בשניהם, או משתמשים רק באתר.
- אפשר תמיד לייצא גיבוי JSON מההגדרות, גם כשהסנכרון פעיל.

## מבנה הקוד (למי שרוצה לשנות)
```
index.html             שלד הדף + סדר טעינת הסקריפטים
styles.css             עיצוב (משתני צבע, מצב כהה, טלפון, הדפסה)
js/utils.js            עזרים: תאריכים, טקסט, אייקונים, LaTeX
js/model.js            מבנה הנתונים, תבניות, עדכוני גרסה
js/catalog.js          קטלוג הפקולטה: חובה, קבוצות התמחות, בחירה, מעבדות
js/store.js            שמירה ב-localStorage, Undo, שינויים
js/backup.js           ייצוא, ייבוא, שמירה אוטומטית לקובץ
js/config.js           כתובת ומפתח של Supabase (ריק = מקומי בלבד)
js/cloud.js            התחברות וסנכרון עם הענן
js/stats.js            חישובי התקדמות וקצב
js/grades.js           חישובי ציונים
js/timer.js            טיימר פומודורו ויומן לימוד
js/ui.js               חלונות, תפריטים, הודעות, גרירה
js/views/*.js          המסכים (דשבורד, קורס, מערכת, סטטיסטיקות...)
js/app.js              ניווט, חיפוש, קיצורי מקלדת
vendor/katex/          ספריית KaTeX מקומית להצגת נוסחאות (רישיון MIT)
supabase/schema.sql    הגדרת טבלת הנתונים והרשאות בענן
manifest.webmanifest   הגדרות "אפליקציה" לטלפון (שם, אייקון, צבעים)
sw.js                  עבודה בלי אינטרנט (שמירת קבצי האתר בזיכרון)
icons/                 אייקונים למסך הבית
```
בלי שלב בנייה ובלי התקנות. כל גרסה שמורה ב-git: `git log` מציג את ההיסטוריה.
